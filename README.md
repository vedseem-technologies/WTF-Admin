# WTF Admin Panel

The Admin Panel for the WTF (Where's The Food) platform, built with React and Vite. This dashboard allows administrators to manage various aspects of the platform, including orders, services, menus, and content.

## 🚀 Technologies

- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **API Client**: [Axios](https://axios-http.com/)
- **Validation**: [Validator.js](https://github.com/validatorjs/validator.js)

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository
2. Navigate to the admin directory:
   ```bash
   cd WTF-Admin
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:

```bash
npm run dev
```

### Build

Build the project for production:

```bash
npm run build
```

## 📂 Project Structure

- `src/features`: Core business logic and components grouped by feature (Orders, Auth, Menu, Dashboard, etc.)
- `src/components`: Reusable UI components.
- `src/context`: React Context providers for global state management.
- `src/hooks`: Custom React hooks.
- `src/utils`: Utility functions and helpers.

## ✨ Main Features

- **Dashboard**: Overview of platform statistics and key metrics.
- **Order Management**: View and manage customer orders and details.
- **Menu Management**: Manage food items and categories.
- **Service & Occasion Management**: Configure available services and special occasions.
- **Content Management**: Manage banners, carousels, blogs, and testimonials.
- **Authentication**: Secure admin login and session management.
