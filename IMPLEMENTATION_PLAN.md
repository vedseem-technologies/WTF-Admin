# 🎯 WTF Admin Panel - Implementation Plan

## Project: Catering Business Admin Panel
**Tech Stack**: Vite + React (JSX) + Pure CSS
**Created**: 2026-01-28

---

## 📋 Module Overview

### 1️⃣ **OCCASIONS**
- Title, Image, Active Toggle
- Frontend: /services/catering/occasions/{name}

### 2️⃣ **SERVICES**
- Buffet, Full Service, Cocktail
- Used for filtering + pricing

### 3️⃣ **CATEGORIES** 
- Buffet, Live Service, Delivery only
- Used for filtering + pricing

### 4️⃣ **MENU CATEGORIES**
- Starter, Main Course, Dessert, etc.
- Category Name, Icon/Image, Order

### 5️⃣ **MENU ITEMS (BULK ADD)**
- Item Name, Image, Veg/Non-Veg, Price, Category, Active, People

### 6️⃣ **DASHBOARD**
- Stats Cards, Orders Chart, Popular Items, Recent Orders

### 7️⃣ **ORDERS LIST**
- Filters: Date, Occasion, Service, Status
- Table View

### 8️⃣ **ORDER DETAIL**
- Customer Info, Event Info, Menu Summary
- Quantity & Price Breakdown
- Status Control
